# NGL Self-Funding Institution — Zero-Point Directive

## Constitutional Invariant

**NGL MUST MAKE MONEY WITHOUT SPENDING MONEY.**

## Terminal Condition 0→1

`Treasury = $0` → `Verified Revenue >= $1` while `Incremental Monetary Operating Expenditure = $0`.

The first dollar is an institutional state transition: proof that NGL can convert authorized capability into externally verified economic value without consuming monetary resources first.

## Economic State Machine

`INTENT → AUTHORITY → OPPORTUNITY → PROPOSAL → ADMISSION → EXECUTION → EVIDENCE → VERIFIED VALUE → TREASURY → EARNED SPEND AUTHORITY → GREATER CAPABILITY`

No state may be skipped because an agent claims success.

## Zero-Capital Rules

- No paid advertising.
- No paid lead lists.
- No contractors.
- No paid infrastructure.
- No inventory.
- No loans or venture capital.
- No monetary operating expenditure before verified revenue.
- Existing human labor, existing accounts, existing software access, existing compute, research, and reasoning may be used.
- After revenue exists, expenditure remains bounded by explicit economic admission rules; revenue does not create unrestricted authority.

## First Economic Primitive

**NGL Transition Admission Review — $150 pilot.**

Unit of analysis: **the right to cause a consequential state transition.**

Scope: one bounded autonomous workflow or agent; no production deployment authority.

## Revenue Admission Gate

`Buyer identified → problem evidenced → offer presented → buyer accepts → payment verified → delivery authorized`

Payment precedes delivery. No buyer, acceptance, or revenue may be asserted without evidence.

## Treasury as Authority

The treasury is both an economic balance and an authority state.

`Permitted Spend = f(Verified Treasury, Constitutional Limits, Economic Risk, Recovery Capacity)`

**Money is not merely fuel. Money is earned authority.**

## Capability-Earning Rule

`Capability(n+1) ← Proof(Capability(n))`

NGL may not infer greater capability from configuration, aspiration, possession of tools, or self-report.

## Proof Ledger

The first successful cycle must establish:

- starting treasury = $0
- incremental monetary operating expenditure = $0
- buyer identity and problem
- offer and acceptance
- payment evidence
- delivered artifact
- buyer acceptance / value evidence
- ending treasury > $0
- next capability admitted from the proof

## Failure Semantics

If required evidence is missing, the transition is **NOT PROVEN**.

If a proposed expenditure cannot establish earned economic authority, it is **DENIED**.

If a revenue claim cannot be independently evidenced, it is **UNVERIFIED** and excluded from treasury authority.

## Meta-Test

The experiment succeeds only if NGL demonstrates:

> **It created value first, proved that value, and only then earned the right to consume resources.**
